# 公民 語句補充 単語帳

中学3年 社会（公民）第3章「公3-1-1 民主政治ってなんだろう」〜「公3-2-8 互いに監視し合う三つの権力」のスライドに出てくる **①②… の語句**を、テストの語句補充問題の形で練習するための単語帳です。

## 使い方

ブラウザで `index.html` を開くだけで使えます（GitHub Pages でも公開しています）。

| モード | 内容 |
| --- | --- |
| カード | 空欄つきの文を見て答えを思い出す → 「覚えた／まだ」で記録 |
| 二択 | 正解と、まぎらわしいダミー（控訴⇔上告、被告⇔被告人 など）の2つから選ぶ |
| 入力 | 空欄に入る語句を入力して判定（漢字でもひらがなでもOK） |
| 一覧 | 単元ごとの語句一覧。赤シート機能つき（タップで答えを表示） |

- 「出題範囲・設定」で単元をしぼり込めます。
- 「苦手だけ」をオンにすると、間違えた語句だけを出題します。
- 番号なしの赤字語句（主権・ドント式・一票の格差 など）も出題できます。
- 学習記録はその端末のブラウザに保存されます。

キーボード操作：カードは `Space` で答え表示、`1` まだ／`2` 覚えた。二択は `1`／`2` で選択、`Enter` で次へ。入力は `Enter` で判定・次へ。

二択のダミー回答は `data.js` の `DUMMY` に1語ずつ用意しています。

## 収録内容

| 単元 | 番号つき語句 |
| --- | --- |
| 3-1-1 民主政治ってなんだろう | ①〜③ |
| 3-1-2 国民の代表を選ぶ選挙 | ①〜⑧ |
| 3-1-3 18歳選挙権と私たち | （番号なし。赤字語句のみ） |
| 3-1-4 国民の願いをかなえるために | ①〜⑥（スライドでは⑤が2回） |
| 3-1-5 世論の形成とメディア | ①〜⑤ |
| 3-2-1 国会の決定は国民の意思 | ①〜⑯ |
| 3-2-2 国会は唯一の立法機関 | ①〜⑧ |
| 3-2-3 行政をまとめる内閣 | ①〜⑫ |
| 3-2-4 暮らしを守る行政 | ①〜③ |
| 3-2-5 人権の尊重と裁判 | ①〜⑨ |
| 3-2-6 民事裁判と刑事裁判 | ①〜⑪ |
| 3-2-7 私たちの司法参加 | ⑫〜⑬ |
| 3-2-8 互いに監視し合う三つの権力 | ①・⑧・⑨ |

3-2-8 の ②〜⑦ は教科書の三権分立の図の空欄で、スライドには答えが書かれていません。一般的な三権分立の図の内容を「三権分立の図（補足）」として入れてあるので、教科書の図と見比べて確認してください。

語句のデータは [`data.js`](data.js) にまとめてあります。
